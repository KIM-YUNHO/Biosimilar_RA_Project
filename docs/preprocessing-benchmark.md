# 전처리 비교 시험 (정답 세트 30쪽)

작성일: 2026-10-09 · 관련: [전처리 실행 계획](preprocessing-plan.md) · 코드: `src/ra_prep/`, `eval/`

## 1. 원칙

- **전처리 파이프라인은 LLM을 호출하지 않습니다.** 사용하는 것은 Docling(레이아웃·표 구조 모델), RapidOCR, 그리고 규칙입니다. 같은 입력이면 같은 결과가 나옵니다.
- 이번 작업에서 Claude가 쓰인 곳은 **정답 세트를 만들 때 한 번**뿐입니다. 쪽 이미지를 직접 보고 정답을 적었으며, 파이프라인에는 들어가지 않습니다.
  - 정답은 후보 출력에서 시작해 원본 쪽 이미지와 칸 단위로 대조하며 고쳤습니다.
  - 따라서 정답은 "사람(이 경우 Claude)이 본 원문"이며, 작성자는 한 명입니다. 사람이 다시 확인하면 신뢰도가 올라갑니다(4장).

## 2. 정답 세트

`eval/gold/manifest.yaml`에 쪽 30개(쪽 PDF는 `eval/gold/pages/`, 정답은 `eval/gold/annotations/`)가 있습니다.

| 분류 | 쪽 | 내용 |
|---|---|---|
| EMA 디지털 표·본문 | g01, g02 | SB17 평가보고서 PK 표(병합 셀), 시험 설계 표 |
| EMA 워터마크 + 표 | g03, g06 | 철회된 중복 허가(Qoyvolma, Eksunbi). 대각선 워터마크 아래 표 이미지 |
| EMA 이미지 표 | g04, g05, g07 | 본문에 그림으로 붙은 PK·ADA·인구통계 표 |
| FDA 이미지 쪽 | g08–g17 | 텍스트층 없는 쪽: 시험 목록, 숫자 표(n(%), 검사치, 가림 표시), 본문, 체크박스 |
| FDA 디지털 | g18–g20 | 심사자 명단, 라벨 요약, 라벨 임상 표 |
| FDA 2009 스캔본 | g21–g23 | 문서에 내장된 옛 OCR 텍스트층 |
| FDA 글꼴 깨진 문서 | g24 | 텍스트층이 문자 치환 상태("LQWHUFKDQJHDEOH") |
| FDA 라벨 그림 쪽 | g25 | 사용설명서 그림 쪽 |
| HC 제품설명서 | g26–g28 | 디지털 표 |
| 가이던스 | g29, g30 | FDA 초안(줄 번호), HC 목차 쪽 |

정답 형식(쪽마다 JSON 1개):
- `text`: 본문 단락·제목·각주 목록(머리말·꼬리말 제외)
- `tables`: 표마다 행 목록. 병합 셀은 시작 칸에 한 번만 적습니다.
- `furniture`: 머리말, 꼬리말, 쪽 번호, 워터마크

## 3. 지표 (`eval/evaluate.py`)

| 지표 | 뜻 |
|---|---|
| text_recall | 정답 단락 중 출력에서 찾은 비율(퍼지 일치 95 이상) |
| cell_recall | 정답 표 칸 중 출력 표에 같은 칸으로 있는 비율(공백·대시·체크 기호 정규화 후 완전 일치) |
| num_cell_recall | 위와 같되 숫자가 든 칸만 |
| row_exact | 정답 행이 출력에서 그대로 재현된 비율(칸 순서 포함) |
| num_in_text | 숫자 칸의 값이 출력 어딘가에 있는 비율(표 구조 없이도 검색에 걸리는지) |
| garbled | 깨진 조각이 이어지는 출력 블록 수 |
| furniture_leak | 머리말·꼬리말 등이 본문 블록으로 남은 수 |
| sec_per_page | 쪽당 처리 시간(CPU 4코어) |
